# Gojo Violet Nebula

[![test](https://github.com/BugLivesMatter/dsh-theme-gojo-violet/actions/workflows/test.yml/badge.svg)](https://github.com/BugLivesMatter/dsh-theme-gojo-violet/actions/workflows/test.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Тема-бандл для Web GUI DeepSeek Harness: фиолетово-лавандовая палитра в обоих
режимах оформления, арт Годжо Сатору как фиксированные обои под фиолетовой
вуалью, сплошной фиолетовый сайдбар и чуть более скруглённые радиусы.

Тема — чистый клиентский бандл: она переопределяет дизайн-токены `--dsw-*` в
рантайме, поэтому host-код, сборка и зависимости для использования не нужны.

## Установка

```bash
git clone https://github.com/BugLivesMatter/dsh-theme-gojo-violet.git
```

Из сессии DSH:

```
plugin_manager action=install_bundle target="<абсолютный путь>/dsh-theme-gojo-violet"
```

Результат установки должен содержать `application: applied`; открытая страница
подхватывает плагин через HMR. Отключается в Settings → Plugins (или
`plugin_manager action=set_plugin`) — возвращается стоковый вид.

Установка связывает эту папку, поэтому её нужно оставить на месте: бандл и обои
отдаются из неё.

## Что меняет

- **Палитра.** Переопределяет штатные токены `--dsw-*` через
  `ctx.theme.overrideTokens(...)`: фиолетовая нейтральная шкала (поверхности,
  текст, границы), электрик-фиолетовый акцент (ссылки, focus ring, выделение,
  бизнес-состояние), перивинкловый синий, розовое/мятное состояние, цвета
  синтаксиса, заливки стеклянных меню и скроллбары. Значения заданы и для
  светлой, и для тёмной темы, поэтому Settings → Appearance продолжает работать.
- **Обои.** Один собственный stylesheet плагина: фиксированная картинка
  `cover` под фиолетовой вуалью, прозрачные колонки оболочки, чтобы она
  просвечивала, а сайдбар сохраняет свою сплошную фиолетовую заливку. В светлом
  режиме та же картинка вымывается в бледно-лавандовую бумагу.
  `prefers-reduced-transparency` откатывает к плоским поверхностям.
- **Радиусы.** Чуть более скруглённая шкала `--dsw-radius-*`.

Типографику тема не трогает: штатные строки Settings → General (семейство и
размер шрифта текста/кода/терминала, за шевроном на строке "Font size")
продолжают работать и перекрывают токены темы.

Тема применяется слоем поверх активной встроенной темы (light/dark), а не как
зарегистрированный сторонний theme id: предпочтение сохраняется, а отключение
плагина полностью возвращает стоковый вид.

## Раскладка

| Файл | Назначение |
|---|---|
| `package.json` | манифест бандла и клиента (`dsh.bundle.patch`, `dsh.client`) |
| `cordis.patch.yml` | вставляет строку `theme-gojo-violet` в Loader |
| `index.js` | host-часть (пустой `apply`; бандлу нужна только строка) |
| `client.js` | сгенерированная браузерная часть: токены + stylesheet обоев |
| `assets/gojo-wallpaper.<hash12>.jpg` | обои 2560×1440, имя с ревизией контента, чтобы кэш `/plugins` оставался валидным |
| `locale/*.json` | название и описание в Plugin Manager (en, ru) |
| `icon.svg` | иконка плагина |
| `_build/` | источник истины палитры, генератор, вспомогательные проверки |

## Пересборка и перекраска

`_build/build.mjs` содержит лестницы палитры (`neutral`, `accent`, `blue`,
`green`, `red`, `violet`) и литеральные алиасы `pairs`. После правки:

```
node _build/build.mjs
```

Генератор пересобирает `client.js`, выпускает обои под новым именем с ревизией
контента и обновляет `_build/tokens.json`. Открытая страница подхватывает
изменённый бандл только после перезапуска строки Loader: выключить/включить
плагин `include:theme-gojo-violet` (Settings → Plugins или
`plugin_manager action=set_plugin`) либо перезапустить DSH. Обычного обновления
страницы недостаточно — Host держит ранее опубликованные байты бандла.

Сами обои получаются из `_build/gojo-source.jpg`; для пересчёта нужен Python с
Pillow и `node _build/make-wallpaper.py` (он пишет `_build/wallpaper-raw.jpg`,
который `build.mjs` затем выпускает под именем с ревизией контента).
`_build/wallpaper-raw.jpg` — промежуточный артефакт и в git не входит.

## Проверка

`_build/smoke-test.mjs` исполняет сгенерированный бандл на заглушках DOM/ui-theme
и проверяет регистрацию, пары токенов, URL обоев и dispose; CI гоняет его на
каждый push. `_build/contrast.mjs` печатает контраст WCAG для ключевых пар
передний план/фон в обеих палитрах.

```bash
node --check client.js && node --check index.js
node _build/smoke-test.mjs
node _build/contrast.mjs
```

## Замечания

- CSS обоев рассчитан на имена классов оболочки той сборки DSH, под которую тема
  делалась (`.mP3x-q_frame/_centerCol/_bottomRow` из `ui-layout`, `.an3WzG_root`
  из `ui-conversation`). Если обновление DSH переименует эти CSS-module хэши,
  список селекторов в `_build/wallpaper.css` нужно обновить; в этом случае тема
  продолжит красить палитру, а арт просто перестанет показываться.
- Не добавлять `backdrop-filter` на `.mP3x-q_sidebarCol`. Свёрнутый сайдбар
  рисует свои кнопки открытия/закрытия через `position: fixed`; фильтр на этой
  колонке становится для них containing block и обрезает их (именно из-за этого
  во время разработки пропадали кнопки сайдбара). Вместо фильтра сайдбар держит
  собственную непрозрачную фиолетовую заливку.
- Арт — файл автора. Он включён, чтобы свежий клон выглядел правильно, но **не**
  покрывается лицензией MIT и не очищен для перепубликации третьими лицами;
  при перепубликации темы замените `_build/gojo-source.jpg` своим изображением.
- Тема меняет только цвета, радиусы и фон; арт продуктовых иконок остаётся
  штатным.
- Скриншоты проверки из живого GUI (`_verify/`) содержат содержимое сессий,
  поэтому они в git не входят и нигде не публикуются.
